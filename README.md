# Nimbu Audio 🎙️
*La plataforma de audios de Hive donde tu voto vale igual*

Nimbu Audio es una plataforma descentralizada dedicada a creadores de audio en Hive. 
Podcasts, música, audiolibros, efectos de sonido, meditaciones. Todo lo que se escucha.

### **¿Qué hace diferente a Nimbu Audio?**
En Hive normalmente el voto depende del stake. Aquí no.

**1 voto = 1 persona** 
Sin importar si tienes 10 HP o 1M HP. Cada cuenta verificada tiene el mismo peso para apoyar a los creadores de audio.

### **Características**

- **🎧 Enfocada en Audio**: Sube, reproduce y descubre solo contenido de audio
- **🗳️ Votación Justa**: Sistema 1-persona-1-v
